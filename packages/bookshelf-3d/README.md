# Bookshelf 3D

A 3D bookshelf visualization built with React Three Fiber.

## Features

- Interactive 3D books with hover animations
- Realistic bookshelf structure with shadows
- Featured book display

## Getting Started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npm run dev
   ```

3. Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

To build for production:

```bash
npm run build
```

## Technologies Used

- React
- TypeScript
- Three.js
- React Three Fiber
- React Three Drei
- Vite
